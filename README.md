# 本地生活服务平台（高并发秒杀 + AI 智能客服增强版）
本项目是一款类似于大众点评的本地生活服务平台，基于**SpringBoot3 + JDK17 + Redis** 构建，聚焦线下商户服务、限时优惠秒杀等核心业务场景，针对高并发、高性能要求做全链路优化，并深度集成**AI 智能交互能力**，实现自然语言驱动的业务查询与个性化服务，兼顾系统性能与用户体验。

## ✨ 技术栈
- 后端：**SpringBoot3**、SpringMVC、MyBatis-Plus、**SpringAI**
- 数据库：MySQL 8.0+、Redis 6.0+
- 消息队列：RabbitMQ 3.0+
- 缓存：Redis + Caffeine （二级缓存）
- 其他：Lua 脚本、ThreadLocal、Maven、hutool 工具集

## 📌 项目背景
针对本地生活服务场景中**高并发秒杀、热点数据查询、用户咨询效率低**等痛点设计：
1. 解决限时优惠券秒杀场景下的超卖、数据库雪崩、接口阻塞等问题；
2. 优化商户热点数据查询性能，提升用户访问体验；
3. 传统客服依赖固定接口与菜单操作，用户使用成本高，因此引入**AI 智能客服**，支持自然语言直接查询商户、优惠券、笔记信息，实现业务系统与大模型无缝联动；

## 🚀 核心功能
### 1. 用户登录与安全控制
- 基于手机号+验证码实现登录注册，验证码带有效期与请求限流，防止恶意刷接口；
- 使用 Redis 存储会话信息，支持分布式会话共享；
- 自定义登录拦截器，完成用户鉴权与权限控制，保证数据安全。

### 2. 商户信息缓存优化
- 采用 Caffeine 本地缓存 + Redis 分布式缓存 二级缓存架构，大幅降低 MySQL 访问压力，热点商户接口响应速度提升 80%+；
- 解决**缓存穿透**：采用缓存空对象策略，拦截无效不存在的商户请求
- 解决**缓存击穿**：实现两套经典方案
  1. 互斥锁机制：控制单线程重建缓存，保障数据强一致性
  2. 逻辑过期方案：不删除缓存、仅标记过期，后台异步更新，高并发下不阻塞业务
- 缓解**缓存雪崩**：缓存过期时间添加随机偏移量，避免批量key同时失效
- 合理维护缓存与数据库最终一致性

### 3. 高并发优惠券秒杀系统
- 基于 **Redis + Lua 脚本** 原子化完成库存扣减、秒杀资格校验，从根源避免超卖；
- 实现**一人一单**功能，防止用户恶意刷单、囤券；
- 引入 RabbitMQ 实现异步削峰，秒杀请求异步处理，提升系统吞吐量；
- 异步创建订单，同步快速返回结果，避免高并发下数据库阻塞。

### 4. AI 智能客服（SpringAI + Function Calling）
- 基于 SpringAI 集成大模型，提供独立聊天界面，**登录后即可使用**；
- 通过 **Function Calling** 实现大模型自动调用后端业务接口：
  - 自然语言查询商户信息、店铺评分、店铺类型；
  - 查询个人可用优惠券、限时活动、优惠券使用规则；
  - 查询探店笔记、热门内容、获取个性化推荐；
- 大模型自动理解用户意图，无需固定参数，直接返回自然语言结果，提升用户体验。

## 💡 项目亮点

## 📦 部署说明
本项目采用 SpringBoot3 单体架构，依赖环境：
- JDK 17+（强制）
- MySQL 8.0+
- Redis 6.0+
- RabbitMQ 3.0+

### 部署步骤
1. 创建数据库，执行项目 SQL 脚本初始化数据；
2. 参考 application-example.yaml 编写自己的 application.yaml 配置文件，配置 MySQL、Redis、RabbitMQ、SpringAI 相关信息；
3. 使用 Maven 打包：`mvn clean package -DskipTests`；
4. 执行 `java -jar` 命令启动项目。

⚠️ 注意事项：
- 项目配置文件未上传至仓库，需自行补充配置；
- SpringAI 需配置有效大模型密钥，支持国内/国际主流模型；
- AI 客服模块严格依赖登录状态，未登录无法访问接口与页面。
